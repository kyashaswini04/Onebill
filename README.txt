OneBill restaurant image assets

Copy the image files in this folder into your React project's src/assets folder.

Suggested photo mapping:
- kfc.jpg -> KFC
- burgerking.jpg -> Burger King
- kfc-burgerking-mcdonalds-banner.png -> combined KFC/Burger King/McDonald's promotional banner
- zafrani-mandi.jpg -> Zafrani Mandi (photo 1, as requested)
- rapol-mandi.webp -> Rapol Mandi (photo 2, as requested)
- bagara-kodi-pulao.jpg -> Bagara Kodi Pulao
- amogha-cakes-banner.png -> Amogha Cakes banner
- chocolate-cake.jpg -> cake/dessert card
- mandi-biryani-banner.png -> Mandi and biryani promotional banner
- restaurant-pastel-collage.png -> restaurant collage banner

Note: The generated promotional banners are decorative graphics; for individual menu cards use the individual food photos when available.
